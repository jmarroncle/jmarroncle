### Lo que estoy construyendo

**[Signal IQ](https://signal-iq-jet.vercel.app)** — Plataforma que unifica VOC (Voice of Customer) y Lead Scoring para equipos de marketing que lanzan productos de inversión: score de lead en 4 dimensiones + clasificación del lenguaje real del cliente + acción recomendada, en un CRM propio.
`Vite · React · TypeScript · Supabase · Vercel · Claude API`

**[Unit Economics Calculator](https://unit-economics-ruddy.vercel.app)** — Calculadora multi-vertical (SaaS, Fintech, Ecommerce, Proptech, Edtech) para simular CAC, LTV y punto de equilibrio, con reportes en PDF y seguimiento histórico.
`Vite · React · TypeScript · Tailwind · Recharts · Supabase`

**[VOC Hub](https://github.com/jmarroncle/voc-hub)** — Prototipo de UX para reemplazar la encuesta post-venta por un mensaje de voz de hasta 2 minutos. En desarrollo: transcripción por IA y dashboard con datos reales.
`Next.js · React`

**Sistema de agentes de marketing** — Un "sistema operativo" de 30+ agentes de IA (Claude Code) que automatiza research, contenido, prospección B2B y seguimiento comercial para una agencia de growth marketing, con un CRM propio en producción.
`Node.js · Next.js · Vercel KV · Claude API`

### Cómo trabajo

- **Behavioral Design primero:** cada sistema que construyo parte de entender por qué la gente realmente decide, no de lo que "debería" funcionar.
- **Simple antes que "correcto":** prefiero una solución simple que resuelve el problema hoy sobre una arquitectura elaborada para un problema hipotético.
- **Documentado para volver:** cada proyecto queda con su README y su porqué, no solo su cómo.
