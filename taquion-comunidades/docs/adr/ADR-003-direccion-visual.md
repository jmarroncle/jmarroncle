# ADR-003 · Dirección visual

**Estado:** ⏳ Pendiente de decisión · **Fecha:** 2026-11-09

## Opciones (ver `design/moodboards/index.html`)
- **A · Tachyon Night** — oscuro, futurista, alta diferenciación.
- **B · Calm Community** — cálido, familiar, menor fricción desde WhatsApp.
- **C · Editorial Pulse** — contraste alto, datos primero, ideal para admin.

## Propuesta inicial
Mezcla **B (experiencia del miembro) + C (panel admin)**; A reservada para landing/marca si se quiere más diferenciación.

## Para decidir
Preferencia del equipo, perfil del público (técnico vs. general) y pruebas rápidas con 3–5 miembros.
